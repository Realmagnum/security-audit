# Changelog

Все изменения и улучшения форка `Realmagnum/security-audit` относительно апстрима `Arturio48/security-audit`.

## [1.1.0] - 2026-10-26

### Исправления безопасности и надежности (Fixes)

#### `scripts/scan-host.sh`
- **Сохранение статуса ошибок (Subshell Fix):** Цикл чтения прав на `.env`-файлы переписан с пайпа (`| while`) на process substitution (`while ... < <(...)`). Это исключило сгорание `fail=1` внутри подоболочки и гарантирует ненулевой код возврата при обнаружении незащищенных секретов.
- **Определение сервисов под root:** Добавлена проверка на отсутствие директивы `User=` в systemd-юните (поведение systemd по умолчанию — запуск от UID 0 / root).
- **Парсинг нескольких `EnvironmentFiles`:** Регулярное выражение `sed` исправлено с жадного `.*` на нежадное удаление маркеров `(ignore_errors=...)`, предотвращая потерю второго и последующих env-файлов.

#### `scripts/scan-web.sh`
- **Проверка кук:** Вызовы `bad()` для кук без флага `Secure` теперь корректно устанавливают флаг ошибки `$fail=1`. Добавлена проверка политики `SameSite`.
- **Исключение ложных срабатываний в SPA:** При статусах `200/206` на пути утечек (`/.git/config`, `/.env`) добавлена валидация `Content-Type` и сигнатур содержимого, исключающая фальшивые P1 на сайтах с клиентским роутингом (SPA catch-all index.html).
- **Поддержка кастомных портов:** Корректный разбор URL вида `https://domain:port/` для TLS-хендшейка openssl.
- **Кроссплатформенность:** Реализован обёртка `run_with_timeout` для совместимости с macOS / BSD, где отсутствует утилита `timeout` из GNU coreutils.
- **Мягкая обработка редиректов главной:** Статусы `301/302/307/308` на корневом URL теперь считаются допустимым редиректом, а не падением доступности.

#### `scripts/audit.py`
- **Аудит деплой-команд:** Устранено слепое пятно в `scan_deploy_excludes`. Теперь проверяются все команды синхронизации/архивации (`rsync`, `tar`), в том числе те, где флаг `--exclude` отсутствует полностью (критическая уязвимость отправки всего каталога с `.env`).
- **Исключение env-шаблонов:** Файлы `.env.example`, `.env.sample`, `.env.template` исключены из ложных алертов о необходимости прав 600.
- **Проверка боевых `.env` в git:** Добавлена проверка `git ls-files` — если боевой `.env` отслеживается репозиторием, генерируется P1-находка.
- **Расширенный детект POST-эндпоинтов:** Добавлена поддержка FastAPI (`@app.post`), Flask (`methods=['POST']`), DRF (`@api_view(['POST'])`). Поиск троттлинга теперь локализован по файлам, а не отключается глобально по первому упоминанию.
- **Новый sink:** Добавлен детект SSTI для `render_template_string` (P1).
- **Гарантированная очистка:** Экспорт зависимостей `.audit-req.txt` обернут в `try...finally`.
